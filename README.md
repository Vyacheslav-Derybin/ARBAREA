# Arbarea — приложение для заказа изделий из дерева

Веб-приложение для мастера, который делает изделия из дерева ручной работы.
Покупатель видит галерею и каталог, выбирает изделие, проходит оплату и получает помощь AI-ассистента.

## Что реализовано

- **Галерея и каталог** — изделия с фотографиями, описаниями и фильтрами;
- **Оплата** — сценарий оформления заказа и оплаты;
- **AI-ассистент** — помогает покупателю выбрать изделие под задачу;
- **Адаптивный интерфейс** — телефон и десктоп.

## Стек

React, TypeScript, Vite, современный фронтенд без тяжёлой инфраструктуры.

## Доказательства

Скриншоты галереи, экрана оплаты и AI-ассистента передаются заказчику отдельно.
Платёжные и персональные данные в примерах закрыты.

## Ограничения

Демо-стенд и исходный код предоставляются по запросу. Публичные тестовые данные не содержат реальных клиентских сведений.
